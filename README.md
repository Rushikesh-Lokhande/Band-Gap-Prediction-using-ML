# Bandgap Prediction using Machine Learning

This project develops multiple machine learning models to predict the bandgap of Li-Fe materials. The models include **Random Forest Regressor**, **XGBoost Regressor**, **Gradient Boosting Regressor**, and **Linear Regression**. The models are trained on a dataset of over 2,900 samples, and their performance is compared using **R²** and **MSE**. The project also includes a **Streamlit web app** for easy interaction and visualization of the results.

## Features
- **Multiple models used**: 
  - Random Forest Regressor
  - XGBoost Regressor
  - Gradient Boosting Regressor
  - Linear Regression
- Comparison of model performance using **R²** and **MSE**
- **Streamlit web app** for interactive predictions and model comparisons
- Trained on 2,900+ data points of Li-Fe material properties

## Technologies Used
- **Python**
- **Scikit-learn** (for Random Forest, Gradient Boosting, Linear Regression)
- **XGBoost**
- **Pandas & NumPy**
- **Matplotlib** (for data visualization)
- **Streamlit** (for creating the web app)
